# Treino 3x3 - aplicativo instalável

Arquivos: index.html (o app), manifest.webmanifest, sw.js (funcionamento offline) e os ícones.
Mantenha todos juntos, na mesma pasta, no mesmo endereço.

## Publicar no GitHub Pages (grátis)
1. Crie uma conta em github.com e entre.
2. Novo repositório (+ > New repository): nome "treino3x3", público, e clique em Create repository.
3. "uploading an existing file": arraste TODOS os arquivos desta pasta (não a pasta em si) e clique em Commit changes.
4. Settings > Pages > Source: "Deploy from a branch", branch main, pasta / (root) > Save.
5. Em 1 a 2 minutos o endereço aparece: https://SEU-USUARIO.github.io/treino3x3/

## Instalar no iPhone/iPad
Abra o endereço no Safari > Compartilhar > Adicionar à Tela de Início.

## Atualizar o app depois
Substitua index.html no repositório. Se mudar outros arquivos, altere o número da versão em sw.js (por exemplo, de treino3x3-v13 para treino3x3-v11).

## Dados
Ficam no aparelho (localStorage). Antes de trocar de endereço ou aparelho, faça o backup em Ajustes e restaure no novo.
